# House Price Prediction using Machine Learning

## Project Overview
This project predicts estimated house prices using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Linear Regression

## Features
- Enter house area
- Select number of bedrooms
- Enter number of bathrooms
- Enter house age
- Predict estimated house price

## Project Files
- main.py - Trains the Machine Learning model.
- app.py - Provides the Streamlit web application.
- house_price_model.pkl - Saved trained model.

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the model:

python main.py

Start the website:

streamlit run app.py
